SECTION 1: PROJECT OVERVIEW
================================================================================

NJ IDE Copier is an intelligent bridge between DeepSeek AI chat and development 
environments. It automatically captures, versions, and transfers code from 
DeepSeek conversations directly into IDEs with smart error tracking and version 
management.

CORE FEATURES:
- Code Block Detection & Extraction
- Full Chat Export
- Version Tracking & Management
- Error Detection & Tracking
- Multi-IDE Support (VS Code, JetBrains, Sublime, etc.)
- Markdown Export
- Clipboard Integration
- Smart Update Handling
- IDE Auto-Detection

SECTION 3: CORE PYTHON FILES TO CREATE
================================================================================

FILE 1: src/core/version_manager.py
-----------------------------------

This file handles code versioning. Copy the complete CodeVersionManager class 
from the chat. Key classes to implement:

1. CodeVersion dataclass - Represents a version of code
2. CodeBlock dataclass - Represents a code block with history
3. CodeVersionManager class - Main version management logic

Key methods:
- add_or_update_block() - Add new or update existing block
- identify_block() - Find matching block for code
- detect_changes() - Detect differences between versions
- detect_error_fix() - Identify if new code fixes errors
- revert_to_version() - Rollback to previous version

FILE 2: src/core/error_tracker.py
----------------------------------

Handles error detection and tracking. Implement ErrorTracker class with:

Key methods:
- track_error() - Record error occurrence
- classify_error() - Categorize error types
- suggest_fix() - Provide fix suggestions
- get_error_statistics() - Generate error reports

Error types to support:
- SyntaxError
- TypeError
- ValueError
- AttributeError
- NameError
- IndexError
- KeyError
- ImportError
- RuntimeError
- IndentationError
- ZeroDivisionError
- FileNotFoundError
- PermissionError

FILE 3: src/core/ide_detector.py
--------------------------------

Detects installed IDEs. Implement IDEDetector class:

Key methods:
- detect_ides() - Find all installed IDEs
- detect_active_ide() - Find currently active IDE
- get_ide_info() - Get IDE details
- list_available_ides() - List all detected IDEs

Supported IDEs:
- Visual Studio Code
- PyCharm
- IntelliJ IDEA
- WebStorm
- PhpStorm
- GoLand
- CLion
- Sublime Text
- Atom
- Notepad++

FILE 4: src/core/code_analyzer.py
---------------------------------

Analyzes code structure. Implement CodeAnalyzer class:

Key methods:
- analyze_python_code() - Parse and analyze Python
- extract_imports() - Find all imports
- extract_functions() - List functions
- extract_classes() - List classes
- calculate_complexity() - Cyclomatic complexity

SECTION 12: COMMON ISSUES & SOLUTIONS
================================================================================

ISSUE: Server won't start
SOLUTION: Check port 8765 is not in use, verify Python version

ISSUE: Extension not connecting
SOLUTION: Ensure server is running, check CORS settings

ISSUE: IDE not detected
SOLUTION: Add IDE manually in config, check PATH

ISSUE: Code not copying
SOLUTION: Check clipboard permissions, verify server connection

ISSUE: Version history missing
SOLUTION: Verify version tracking is enabled in config
