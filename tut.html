📖 Introduction

What is NJ IDE Copier?

NJ IDE Copier is an intelligent bridge between DeepSeek AI chat and your development environment. It automatically captures, versions, and transfers code from DeepSeek conversations directly into your IDE with smart error tracking and version management.

Why Use NJ IDE Copier?

1

Save Time

Eliminate manual copy-paste. Code appears in your IDE with one click.

2

Save Money

Reduce API calls by 30-50% through smart versioning and error detection.

3

Track Everything

Never lose code versions. Rollback to any previous version instantly.

📦 Installation

Step-by-Step Installation

1

Install Python Package

Bash 
pip install nj-ide-copier
2

Start the Server

Bash 
nj-ide-copier start

✅ Server running on http://localhost:8765

3

Install Browser Extension

Chrome 
1. Open chrome://extensions/
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select browser_extension/ folder
4

Install VS Code Extension

VS Code 
code --install-extension nj-ide-copier

Installation Checklist

  • Python installed and in PATH
  • NJ Copier package installed
  • Server running successfully
  • Browser extension loaded
  • VS Code extension installed
  • IDE detected by system

⚙️ Configuration

Basic Configuration

Create configuration file at ~/.nj-ide-copier/config.json:

JSON 
{
  "server": {
    "port": 8765,
    "host": "localhost"
  },
  "ide": {
    "default": "auto",
    "auto_detect": true
  },
  "features": {
    "version_tracking": true,
    "error_detection": true,
    "auto_copy": true
  }
}

VS Code Settings

Setting Default Description
serverPort 8765 Port for local server
autoStart true Auto-start on VS Code launch
autoInsert true Auto-insert at cursor
trackVersions true Track code versions
formatOnInsert true Format code automatically

🎯 Advanced Features

Version Management

Automatic Version Tracking

Every code change creates a new version. Track evolution, compare changes, and rollback when needed.

Bash 
# View version history
nj-ide-copier history --block-id abc123

# Revert to version
nj-ide-copier revert --block-id abc123 --version v2

# Compare versions
nj-ide-copier diff --block-id abc123 --v1 v1 --v2 v2

Error Detection & Tracking

Smart Error Detection

Automatically detects errors in code, suggests fixes, and tracks error patterns over time.

Project Organization

Bash 
# Create project
nj-ide-copier project create my-project

# Add code to project
nj-ide-copier project add --project my-project --file code.py

# Export project
nj-ide-copier project export --project my-project --format zip

🔧 Troubleshooting

Common Issues & Solutions

Server won't start
Bash 
# Check port usage
lsof -i :8765

# Kill process using port
kill -9 $(lsof -t -i:8765)

# Start with debug logging
nj-ide-copier start --debug
Extension not working
  1. Check if server is running
  2. Reload extension in browser
  3. Clear browser cache
  4. Check console for errors
IDE not detected
Bash 
# Check IDE installation
which code  # VS Code
which pycharm  # PyCharm

# Add IDE manually
nj-ide-copier ide add --name "VS Code" --command "/path/to/code"

❓ Frequently Asked Questions

Is my code stored securely?

Yes, all code is stored locally on your machine. You can enable encryption for additional security. No data is sent to external servers.

Does it work offline?

Yes, the system works entirely locally. Once code is captured, you can access it without an internet connection.

Can I use multiple IDEs?

Yes, the system supports multiple IDEs and can automatically detect which one you're currently using.

Is it free?

Yes, the basic version is completely free and open source. It can actually save you money by reducing API calls.
